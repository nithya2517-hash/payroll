💡 กฎหัก: ค่าไฟ(หารตามห้อง)+ค่าน้ำ(งวด16-สิ้นเดือน)+ปกส.ลูกจ้าง → หักจากค่าแรงรายวัน • ปกส.นายจ้าง(ssoEmr) → หักจากเงินพิเศษ • เงินพิเศษหักตามวันขาด/ลา/สาย (ไม่ติดลบ) • OT 1.5/2/3 • พนักงานรายเดือน = เงินเดือน÷2 ต่องวด

🚀 การใช้งาน 5 ขั้นตอน

1. เพิ่มพนักงาน
แท็บ 👥 (รายวัน/รายเดือน)
2. บันทึกเวลา
แท็บ ⏰ (มา/ขาด/ลา/OT/สาย)
3. มิเตอร์ไฟ
แท็บ 🏠 กรอกก่อน/ล่าสุด
4. รายการงวด
แท็บ 💵 (เบิก/กู้)
5. คำนวณ+พิมพ์
แท็บ 🧮 → 🖨️ เอกสาร

➕ เพิ่ม / แก้ไขพนักงาน

💰 ปุ่มม่วง = ใส่เงินพิเศษ+ฝ่าย+ห้องอัตโนมัติ (มอ 1330 / เอ้ย-โทน-เอก 2030 / อ๋า 1470 / ชาน 980 / เวย 630 / ซ่าน-โจ 1540 / ลิน 1610)

📋 รายชื่อพนักงาน (0)

รหัสชื่อฝ่ายห้องประเภทค่าแรง/เดือน💰 พิเศษธนาคาร/บัญชีจัดการ

⏰ บันทึกเวลาทำงาน (รายวัน)

ℹ️ OT: ปกติ ×1.5 | วันหยุด ×2 | นักขัตฤกษ์ ×3 • สาย: หักจากเงินพิเศษตามนาที

📅 บันทึกเวลาทั้งหมด

พนักงานวันที่สถานะประเภทวันลาสาย(น.)OT(ชม.)จัดการ

🏠 มิเตอร์ไฟรายห้อง (รอบบิลนี้)

💡 ค่าไฟ = (ล่าสุด − ก่อน) × ราคา/หน่วย (ตั้งค่า) ÷ จำนวนผู้พักในห้อง

📋 ตารางห้อง/ค่าไฟ

ห้องก่อนล่าสุดหน่วยรวม(บาท)คนต่อคนผู้พักจัดการ

💵 รายการพิเศษ / เบิก / กู้ (รายงวด)

💡 "เงินพิเศษ" ดึงจากประวัติพนักงานอัตโนมัติ — ไม่ต้องกรอกที่นี่

📋 รายการที่บันทึก

พนักงานงวดรับอื่นเบิกกู้หักอื่นจัดการ

🧮 คำนวณเงินเดือน

🖨️ เอกสารงวด (พิมพ์ / Save PDF)

⚠️ ต้องกดคำนวณงวดนั้นก่อน (แท็บ 🧮) จึงจะพิมพ์เอกสารได้

📈 รายงานสรุปงวด

🏢 ข้อมูลบริษัท (แสดงบนสลิป)
