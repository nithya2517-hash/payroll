> 🔗 **เว็บไซต์โครงการ (GitHub Pages):** https://nithya2517-hash.github.io/payroll/
> 📦 **คลังโค้ด (Repository):** https://github.com/nithya2517-hash/payroll

โปรแกรมสำเร็จรูปคำนวณค่าแรงพนักงานรายวันแบบครบวงจร ตามกฎหมายคุ้มครองแรงงานไทย
**ไฟล์เดียวจบ** (`payroll_app.py`) ไม่ต้องติดตั้งไลบรารีเพิ่ม (ใช้เฉพาะ Standard Library)
ครอบคลุม: ลงเวลา → คำนวณค่าแรง/OT/ลา → หักประกันสังคม/เบิก/กู้ → ออกสลิป → รายงานสรุป

## ✨ ความสามารถ

- ➕ จัดการข้อมูลพนักงาน (เพิ่ม / ดูรายชื่อ)
- ⏰ บันทึกเวลาทำงานรายวัน (มา / ขาด / ลา) + ชั่วโมง OT + ประเภทวัน
- 📥 นำเข้าเวลาทำงานจากไฟล์ CSV (รองรับไฟล์จากเครื่องสแกนเวลา)
- 🧮 คำนวณเงินเดือนอัตโนมัติตามงวด (1–15 / 16–สิ้นเดือน / ทั้งเดือน / กำหนดเอง)
- 💵 รองรับรายการพิเศษ: เบี้ยเลี้ยง, เบิกล่วงหน้า, เงินกู้, หักอื่น ๆ
- 🧾 ออกสลิปเงินเดือนรายคน (HTML → พิมพ์เป็น PDF ได้ทันที)
- 📊 รายงานสรุปงวด (HTML + CSV เปิดใน Excel ได้ไม่เพี้ยน)
- 🗄️ ฐานข้อมูล SQLite ในไฟล์ `payroll.db` (ไม่ต้องลงเซิร์ฟเวอร์)
- 🎁 มีข้อมูลตัวอย่าง (เดโม) ให้ทดลองได้ทันที

## ⚖️ กฎเกณฑ์การคำนวณ (กฎหมายแรงงานไทย)

| รายการ | กฎเกณฑ์ |
|---|---|
| ชั่วโมงทำงานปกติ | 8 ชม./วัน (48 ชม./สัปดาห์) |
| OT วันทำงานธรรมดา | 1.5 เท่า ของค่าจ้างต่อชั่วโมง |
| OT วันหยุดประจำสัปดาห์ | 2 เท่า |
| OT วันหยุดนักขัตฤกษ์ | 3 เท่า |
| ทำงานในวันหยุด (ลูกจ้างรายวัน) | ได้ค่าแรงวันนั้น + เพิ่มอีก 1 เท่า |
| ประกันสังคม | 5% ของค่าจ้าง (สูงสุด 750 บาท/เดือน) |
| ลาป่วย | ได้ค่าจ้างไม่เกิน 30 วัน/ปี |
| ลากิจ | ได้ค่าจ้างไม่เกิน 3 วัน/ปี |
| ลาพักร้อน | ไม่น้อยกว่า 6 วัน/ปี |
| วันหยุดนักขัตฤกษ์ | 13 วัน/ปี (ปรับได้ในโค้ด) |

> ⚠️ ค่าแรงเริ่มต้น 372 บาท/วัน — แก้ไขได้ตามจังหวัด/ประกาศล่าสุด

## 🚀 การติดตั้งและใช้งาน

**ความต้องการ:** Python 3.8+ (ไม่มีไลบรารีภายนอก)

```bash
git clone https://github.com/nithya2517-hash/payroll.git
cd payroll
python payroll_app.py
```

หรือดาวน์โหลดไฟล์ `payroll_app.py` จากเว็บนี้แล้วรันได้เลย:
```bash
python payroll_app.py
```

### 🎯 ทดลองเร็วสุดใน 4 ขั้นตอน
```
เมนู 9 → สร้างข้อมูลตัวอย่าง (EMP001–003 งวด 1–15 ส.ค. 2569)
เมนู 6 → คำนวณเงินเดือน (เลือกงวด 1)
เมนู 7 → ออกสลิปเงินเดือน
เมนู 8 → ดูรายงานสรุป
```
ไฟล์ผลลัพธ์ทั้งหมดอยู่ในโฟลเดอร์ `output/`

## 📋 เมนูการใช้งาน

| เมนู | ความสามารถ |
|---|---|
| 1 | เพิ่มพนักงาน |
| 2 | ดูรายชื่อพนักงาน |
| 3 | บันทึกเวลาทำงานรายวัน |
| 4 | นำเข้าเวลาทำงานจาก CSV |
| 5 | เพิ่มรายการพิเศษ / เบิก / กู้ / หัก |
| 6 | คำนวณเงินเดือนตามงวด |
| 7 | ออกสลิปเงินเดือน (HTML → PDF) |
| 8 | รายงานสรุปงวด (HTML + CSV) |
| 9 | สร้างข้อมูลตัวอย่าง (เดโม) |
| 0 | ออกโปรแกรม |

## 🗄️ โครงสร้างฐานข้อมูล (`payroll.db` — SQLite)

| ตาราง | ใช้เก็บ |
|---|---|
| `employees` | รหัส, ชื่อ, ตำแหน่ง, แผนก, ค่าแรง/วัน, ธนาคาร, สถานะ |
| `attendance` | เวลาทำงานรายวัน: วันที่, OT, ประเภทวัน, การลา, สถานะ |
| `adjustments` | รายการพิเศษ/เบิก/กู้/หัก ต่อพนักงานต่องวด |
| `payroll` | ผลคำนวณรายงวด: รายได้, รายการหัก, เงินสุทธิ |

## 📥 รูปแบบ CSV สำหรับนำเข้าเวลาทำงาน

```csv
emp_id,work_date,ot_hours,day_type,leave_type,status
EMP001,2026-08-01,0,normal,none,present
EMP001,2026-08-02,2,normal,none,present
EMP001,2026-08-08,0,normal,none,absent
EMP001,2026-08-14,0,normal,sick,leave
```
ค่าที่ใช้ได้: `day_type` = normal / holiday / special • `status` = present / absent / leave • `leave_type` = sick / personal / annual / unpaid

## ⚙️ การตั้งค่ากิจการ

เปิด `payroll_app.py` แล้วแก้ไขค่าด้านบนสุดของไฟล์:
- `COMPANY_NAME`, `COMPANY_ADDRESS`, `COMPANY_TAX_ID`, `COMPANY_TEL` (แสดงบนสลิป)
- `DEFAULT_DAILY_RATE`, `SSO_RATE`, `SSO_MAX_MONTH`
- `HOLIDAYS` (วันหยุดนักขัตฤกษ์ประจำปี)
